The main objectives of this project are:

## 5. Installation and Setup

To download this repository:

1. Open Git Bash.
2. Clone the repository:

```bash
git clone https://github.com/AYMA33/hello-world.git
```

3. Enter the project directory:

```bash
cd hello-world
```

4. Open the project files using your preferred code editor.

## 6. Git Commands

The following commands are used to manage this project:

```bash
git status
git add .
git commit -m "Update project"
git push origin main
git pull origin main
```
